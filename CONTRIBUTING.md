# Contributing

Thanks for helping make this atlas more accurate and usable.

For a bug, include the page URL, browser, device size, expected result and observed result. For a historical correction, include the place, displayed date, exact current claim, proposed correction, and a reliable source with the relevant passage or page. Explain uncertainty and whose lives the claim describes. The [historical correction issue template](.github/ISSUE_TEMPLATE/historical-correction.yml) prompts for these details.

For a new journey, start with one bounded date and two stable place IDs. Add topic claims and source IDs in `public/content.js`; separate modern geographic locators from historical political labels. Never copy images from a source page without an item-level reuse grant and attribution. Mark reconstructions as such. Run `npm test`, inspect desktop and mobile in a real browser, and check direct shared links, keyboard access and missing coverage.

Opening an issue or pull request does not make a claim live. Maintainers review chronology, source scope, wording, media permissions and UI behavior before merge.
