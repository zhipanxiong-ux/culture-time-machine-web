# Project audit · 8 October 2026

The parent workspace is a no-build `index.html` browser app with a Three.js globe, timelines, historical records and comparison flows, plus two macOS outputs. It opens directly with `file://` and has extensive smoke tests. The parent repository has no configured Git remote and carried substantial unrelated uncommitted research and media work when this web task began. No Cloudflare hosting configuration was present.

The reusable parts are the interaction idea, the curated 750 CE comparison direction, source references, modern-coastline orientation and the rule that national labels are not timeless. The existing package is unsuitable as a first public upload: `index.html` is about 940 KB, the broader `assets/` tree is hundreds of MB, and the parent's rights audit still marks many bundled assets unresolved or conditional. Its native and episode files also do not belong in a public web deploy. We therefore created an isolated, static public edition, keeping the parent app untouched.

The web edition uses a small orthographic canvas globe and an original Natural Earth public-domain land mask. It has one reviewed journey, four evidence-focused topics, direct source links, a time drive with explicit unsupported years, and query-string sharing. The browser can render its core content from `file://`; Cloudflare supplies only static hosting and a real `/api/health` endpoint. No database is justified for this read-only release.

The comparison is about the capital regions of Chang’an and Heijō-kyō around 750 CE. [The Met's Tang essay](https://www.metmuseum.org/essays/tang-dynasty-618-906) supports the broad Chang’an urban and exchange context; [UNESCO](https://whc.unesco.org/en/list/870/) dates Nara's capital era to 710–784; [Nara's excavated tablet reports](https://www.nabunken.go.jp/english/historical-material/5.html) offer specific 745–747 tax and office evidence. Sources have unequal granularity. The topic copy says so and avoids reconstructing a universal meal or home from court evidence. The Japan Met chronology is a secondary period cross-check. The first journey does not certify all historical claims in the parent archive.

Cloudflare Wrangler 4.148.0 is pinned with a lockfile. This task's machine has GitHub CLI access, but Wrangler `whoami` reported no Cloudflare login. A clean public GitHub repository now contains only this standalone web package, without the parent repository or its history. Domain selection and ownership remain open.
